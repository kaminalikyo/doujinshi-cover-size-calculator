# 同人誌封面尺寸計算機
Doujinshi Cover Size Calculator

一款為同人創作者設計的免費線上小工具，協助計算同人誌封面的展開尺寸，並自動產生 Photoshop 參考線腳本。

不需要額外安裝，瀏覽器即可使用。

## 線上使用

🔗 **[開啟同人誌封面尺寸計算機](https://kaminalikyo.github.io/doujinshi-cover-size-calculator/)**

※ 請將網址替換成實際的 GitHub Pages 網址。

## 功能介紹

### 1. 封面尺寸計算

- 支援 A4、A5、A6、B5、B6 等常用尺寸。
- 可以自由輸入書籍完成尺寸（mm）。
- 自訂出血、摺口及書背厚度。
- 支援膠裝與騎馬釘。
- 支援左翻、右翻的封面配置。
- 提供 300、350、600 dpi 像素換算。
- 即時計算封面展開尺寸。

### 2. Photoshop 參考線腳本

依據輸入的尺寸，自動計算水平與垂直參考線位置。

- 即時顯示參考線座標（mm）。
- 一鍵複製 Photoshop JSX 腳本。
- 可下載腳本並於 Photoshop 執行。
- 自動略過重複座標。

### 3. 離線使用

本工具以 HTML、CSS、JavaScript 製作，不需要資料庫或伺服器。

下載 `index.html` 後，可以直接使用瀏覽器開啟。

## 使用方法

1. 選擇書籍尺寸，或自行輸入完成尺寸。
2. 選擇裝訂方式與翻頁方向。
3. 輸入出血、摺口及書背尺寸。
4. 選擇需要的解析度。
5. 查看自動計算的封面展開尺寸及參考線座標。
6. 如需製作 Photoshop 參考線，複製或下載 JSX 腳本。

### Photoshop 腳本使用方式

1. 在 Photoshop 建立符合計算結果尺寸的文件。
2. 將產生的腳本儲存為 `.jsx` 檔案。
3. 在 Photoshop 選擇「檔案 → 指令碼 → 瀏覽」。
4. 選擇腳本檔案並執行。
5. 確認參考線是否正確建立。

## 注意事項

- 本工具僅提供尺寸計算輔助，不保證適用於所有印刷廠。
- 書背厚度、出血與摺口規格，請以合作印刷廠提供的資訊為準。
- 不同裝訂方式可能有不同的封面製作規範。
- px 數值依照選擇的 dpi 換算並四捨五入。
- 正式送印前，請再次確認封面與封底的方向、完成尺寸及參考線位置。
